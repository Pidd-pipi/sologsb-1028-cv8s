# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与发布五个工作区。
- 发布与修订流程：
  - 已发布组件只读；点“创建修订”会把已发布版复制为待审草稿（原发布版保持不变、随时可在“版本”中查看），同时只允许存在一个进行中的修订。
  - 属性改名只会按依赖关系或代码中的旧名匹配、同步引用它的示例，其他示例完全不动。
  - 键盘行为、读屏说明或交互签名变化后，所有关联示例转为“待确认”，必须逐条人工确认。
  - 删除属性会让引用它的示例“引用失效”，修复代码/依赖后可重新校验。
  - 规范存在错误，或还有失效、待确认示例时不能发布；发布失败不会冻结任何快照。
  - 只有发布成功才冻结新快照：旧快照永不改变，修订发布后新内容覆盖回原组件（id 与历史保留），原发布版仍可在快照中查看。
  - 修订草稿自动保存到本地，重新打开页面可继续处理，也可以放弃修订（已发布版不受影响）。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和待确认示例；错误项会阻止发布。
- 版本差异：修订草稿可随时对比已发布基线；发布后可在冻结快照中浏览各版本的属性、无障碍说明和示例。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`（发布、创建/放弃修订等流程操作会重置历史）。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 发布（待审组件）。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v1`。清除站点数据会恢复到内置示例数据。
