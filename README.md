# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移五个工作区。
- 修订流程：已发布组件只读，点“创建修订”（`Alt+R`）把当前发布版完整复制为待审草稿；草稿自动保存在本地，刷新或重新打开页面后仍可继续处理，同一发布版只保留一个进行中的草稿，也可随时放弃修订。修订期间原发布版照旧可查。
- 定向失效传播：属性改名只同步更新引用它的示例（依赖勾选或代码中出现旧名）并保留其他示例；键盘行为、读屏说明或交互签名变化时，所有关联示例一律变为“待确认”，需逐例核对后才能发布。
- 发布门禁：存在规范错误（重名/空属性、缺键盘或读屏说明、空示例、失效属性引用）或仍有待确认示例时不能发布；发布失败不会产生任何快照变化。
- 冻结快照：发布成功才冻结新快照（版本号自增），历史快照永不改写；版本面板可切换查看每个发布版本并与当前内容比较差异，保留最近 12 个快照。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例和失效属性引用，并在发布前列出全部阻断项。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Alt+R` 为已发布组件创建修订，`Cmd/Ctrl+S` 发布当前草稿/修订。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v1`。清除站点数据会恢复到内置示例数据。旧版本地数据中已发布但缺少冻结快照的组件，会在加载时自动补齐与当前版本一致的基线快照，作为修订差异的起点。
